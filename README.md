# 0-1 背包动态规划可视化项目

> 动态规划课程项目 · 第二小组：吴艺莹（42412090）、董思彤（42412092）、王玮玮（42412089）

## 项目简介

本项目实现 0-1 背包问题的动态规划交互式可视化：可观察 DP 表格的逐步计算过程，支持单步推演与自动播放，并支持回溯求出构成最优解的物品集合。页面已接入 OpenMAIC 仿真课堂，可在浏览器中直接体验。

## 本地运行

无需安装任何环境：

1. 下载本仓库；
2. 用浏览器（Chrome / Edge）直接双击打开 `visualization/dp-visualizer.html`。

页面为自包含单文件（内联全部 CSS 与 JS，无外部依赖、无网络请求），离线也能运行。

## 演示样例

- 物品输入：`2,3; 3,4; 4,5; 5,6`
- 背包容量：W = 8
- 预期最大价值：**10**（选取第 2、4 件物品，总重量 3+5=8）

输入格式：`重量,价值;重量,价值;……`，物品之间用**英文分号** `;` 分隔，重量与价值之间用**英文逗号** `,` 分隔。使用中文全角标点会导致解析失败。

## 功能清单

1. DP 表格逐步填充，当前计算单元格高亮
2. 转移来源高亮（「放入」与「不放入」两个候选子问题）
3. 单步执行、自动播放、重置
4. 回溯，输出最优解所选中的物品及其总重量
5. 支持自定义物品与背包容量输入

## OpenMAIC 接入方式

新建课堂 → 添加「交互场景」组件 → `widgetType` 设置为 `simulation` → 将 `visualization/dp-visualizer.html` 的**全部源码**完整粘贴进 `html` 字段 → 保存。课堂内另加一个独立「文本」组件，用于说明问题背景、操作指引与演示样例。详见 `report/OpenMAIC接入说明.docx`。

## 复杂度

| 版本 | 思路 | 时间 | 空间 |
| --- | --- | --- | --- |
| 暴力穷举 | 枚举 2^n 个物品子集 | O(2^n·n) | O(n) |
| 记忆化 | 递归 + 缓存 | O(nW) | O(nW) |
| 递推表（主实现） | 二维数组自底向上 | O(nW) | O(nW) |
| 一维滚动 | 内层容量逆序遍历 | O(nW) | O(W) |

`:warning:` 一维优化的内层容量必须**逆序**遍历，正序会退化为完全背包。

## 输入限制

- 输入需符合 `重量,价值;重量,价值;……` 格式，重量与价值均为非负整数
- 容量或重量为负数、物品格式不是二元组时，算法入口抛 `ValueError`
- 当前版本面向小规模样例演示，物品数或容量过大时表格渲染会变慢
